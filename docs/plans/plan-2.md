# harness-telemetry — Plan 2: inventory, branch-coverage closure, pure extraction (B0 + B1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the vendored reference tokenomics into the repo's own engine (`tokenomics/hooks`, `tokenomics/scripts`, `tokenomics/engine`, `tokenomics/extensions`) with every test-automation assumption lifted into configuration or a TA extension — proven byte-identical to the reference on the whole corpus, after the corpus has first been made to exercise every branch of the reference.

**Architecture:** Three stages, strictly in order. **B0** produces a machine-checked inventory of every domain-coupled site in the reference, each assigned to *engine-config*, *ta-extension* or *retired*. **Coverage closure** extends the Plan 1 coverage gate from functions to branch blocks and drives open branches to zero with corpus cases, failure-state cases or justified exclusions (spec §18.3) — the hard entry gate for B1. **B1** copies the reference tree into the engine location (zero diff by construction), then lifts inventory sites into `engine/config.mjs` (TA defaults) and `extensions/test-automation.mjs` one category per commit, with the differential gate (engine output == reference goldens, byte for byte, every case) green after every commit.

**Tech Stack:** Node ≥ 18.19, ESM, stdlib only, `node:test`, V8 coverage (`NODE_V8_COVERAGE`). Repo: `~/dev/harness-telemetry` (branch `main`, starts at tag `v0.1.0-rc.1` = `794cc73`).

**Spec:** `~/dev/harness-telemetry/docs/spec.md` (v4.2) — §14.1 (engine layout, one copy), §14.3 (TA extension interface), §14.4 (configuration), §14.7 (B1 output is *not* port-conformant), §14.8 (B2 list — NOT in this plan), §18.2 (differential harness), §18.3 (coverage gate). Plan 1's record: `docs/plans/plan-1-ledger.md` (rulings R1–R9, F1–F3, deferred minors).

**Not in this plan:** B2 behaviour migrations (Plan 3), B3 install/activation/probe/git fallback (Plan 4), B5/B4 sdlc-skills consumption + shadow/cutover (Plan 5), C1–C2 porting skill (Plan 6), A5 export.

## Review Focus

1. **A lifted constant that changes a byte** (path joined differently, default applied in a different order, a regex rebuilt from config with different flags) → the differential gate must fail on it. Pinned by Task 8 Step 4 (gate fails on a deliberately mutated engine file) and run after every commit of Tasks 9–11.
2. **An extension hook that is silently skipped** (wrong name, wrong arity) so TA behaviour vanishes but no corpus case notices → the extension contract test asserts every hook is called on the TA cases that exercise it. Pinned by Task 10 Step 1.
3. **A foreign configuration that still runs TA code** (extension `null` but a TA branch still taken) → spy test with `extension: null`. Pinned by Task 10 Step 5.
4. **Coverage closure by exclusion instead of by case** (gate goes green by listing everything) → exclusion budget: `approved-reachable` + `unreachable` branch exclusions ≤ 15% of all branch blocks per file, each with a reason ≥ 40 chars citing code. Pinned by Task 3 Step 1.
5. **An inventory site nobody assigned** (new reference pattern the scanner misses) → scanner categories are tested against planted snippets, and the gate fails on any unassigned or stale assignment. Pinned by Task 1 Step 1.

Categories (each a regex over a single source line; a line can yield several sites):

| category | pattern (JS regex source) | what it catches |
|---|---|---|
| `path-automation` | `['"\`][^'"\`]*automation[^'"\`]*['"\`]` | literal paths/segments containing `automation` |
| `intent-default` | `intent\s*(\?\?\|\|\||=)\s*['"]automation['"]` | default intent |
| `delivered-vocab` | `['"](delivered\|defect-found\|automated\|merged-sanctioned-red)['"]` | outcome vocabulary |
| `case-id-miner` | `extractCaseIds\|[A-Z]\[A-Z0-9\]\|CASE_ID\|caseId(s)?\s*=` | id mining |
| `receipt-reader` | `report\.json\|loadReceipts\|receiptCaseIds\|_returns\|returns/` | receipt/return parsing |
| `gate-records` | `gate-runs\|gateRuns\|foldGateRuns\|gate\.verdict` | QA gate records |
| `stage-words` | `\b(triage\|analyst\|reviewer\|implementer\|scout)\b` inside a string or regex literal | TA stage classification |
| `sizing` | `\.agents/estimation\|sizing\|story_points\|bySize` | predicted-size enrichment |
| `qa-wording` | `['"\`][^'"\`]*(delivered \(automated\)\|cases?\b)[^'"\`]*['"\`]` inside report renderers | QA wording |
| `export-qa` | `scenarios_\|work_item_level\|factory-profile` | QA export fields |
| `env-var` | `TOKENOMICS_[A-Z_]+` | env switches (document; usually engine-config) |

`scripts/inventory.mjs`:
```js
#!/usr/bin/env node
// B0 inventory (spec §14.3, Plan 2): every domain-coupled site in the reference,
// each assigned to engine-config | ta-extension | retired. The gate fails on any
// unassigned, stale or invalid assignment.
import { readFileSync, readdirSync, writeFileSync, mkdirSync, existsSync } from 'node:fs';
import { createHash } from 'node:crypto';
import { join } from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';
import { refDir } from './vendor-reference.mjs';

const ROOT = fileURLToPath(new URL('..', import.meta.url));
const OWNERS = new Set(['engine-config', 'ta-extension', 'retired']);

export const CATEGORIES = [
  ['path-automation', /['"`][^'"`]*automation[^'"`]*['"`]/],
  ['intent-default', /intent\s*(\?\?|\|\||=)\s*['"]automation['"]/],
  ['delivered-vocab', /['"](delivered|defect-found|automated|merged-sanctioned-red)['"]/],
  ['case-id-miner', /extractCaseIds|\[A-Z\]\[A-Z0-9\]|CASE_ID|caseIds?\s*=/],
  ['receipt-reader', /report\.json|loadReceipts|receiptCaseIds|_returns|returns\//],
  ['gate-records', /gate-runs|gateRuns|foldGateRuns|gate\.verdict/],
  ['stage-words', /(['"`/][^'"`/]*\b(triage|analyst|reviewer|implementer|scout)\b[^'"`/]*['"`/])/],
  ['sizing', /\.agents\/estimation|sizing|story_points|bySize/],
  ['qa-wording', /['"`][^'"`]*(delivered \(automated\)|\bcases?\b)[^'"`]*['"`]/],
  ['export-qa', /scenarios_|work_item_level|factory-profile/],
  ['env-var', /TOKENOMICS_[A-Z_]+/],
];

const isComment = (line) => /^\s*(\/\/|\*|\/\*)/.test(line);
const sha = (s) => createHash('sha1').update(s).digest('hex').slice(0, 10);

export function scanSource(file, text) {
  const out = [];
  text.split('\n').forEach((raw, i) => {
    if (isComment(raw)) return;
    const snippet = raw.trim();
    for (const [category, re] of CATEGORIES) {
      if (re.test(raw)) out.push({ id: `${file}:${category}:${sha(snippet)}`, file, line: i + 1, category, snippet: snippet.slice(0, 160) });
    }
  });
  // identical snippets in one file (same category) collapse to one site: they get one assignment
  const seen = new Set();
  return out.filter((s) => (seen.has(s.id) ? false : seen.add(s.id)));
}

export function scanReference(refRoot) {
  const sites = [];
  for (const dir of ['hooks', 'scripts']) {
    for (const f of readdirSync(join(refRoot, dir)).sort()) {
      if (!f.endsWith('.mjs') || f.endsWith('.test.mjs')) continue;
      sites.push(...scanSource(`${dir}/${f}`, readFileSync(join(refRoot, dir, f), 'utf8')));
    }
  }
  return sites;
}

export function checkAssignments(sites, assignments) {
  const ids = new Set(sites.map((s) => s.id));
  const unassigned = sites.filter((s) => !assignments[s.id]);
  const stale = Object.keys(assignments).filter((id) => !ids.has(id)).sort();
  const invalid = [];
  for (const [id, a] of Object.entries(assignments)) {
    if (!ids.has(id)) continue;
    if (!OWNERS.has(a?.owner)) invalid.push({ id, problem: `owner must be one of ${[...OWNERS].join(', ')}` });
    else if (typeof a.target !== 'string' || !a.target.trim()) invalid.push({ id, problem: 'target required' });
    else if (a.owner === 'retired' && !a.target.startsWith('retired:')) invalid.push({ id, problem: "retired target must start with 'retired:'" });
  }
  return { unassigned, stale, invalid };
}

function renderMarkdown(sites, assignments) {
  const by = (o) => sites.filter((s) => assignments[s.id]?.owner === o);
  const row = (s) => `| \`${s.file}:${s.line}\` | ${s.category} | \`${s.snippet.replace(/\|/g, '\\|').slice(0, 90)}\` | ${assignments[s.id]?.target ?? '—'} |`;
  const table = (list) => `| site | category | snippet | target |\n|---|---|---|---|\n${list.map(row).join('\n')}`;
  return `# B0 inventory — reference 49577c7\n\nGenerated by \`node scripts/inventory.mjs --write\`. Sites: ${sites.length}.\n\n## engine-config (${by('engine-config').length})\n\n${table(by('engine-config'))}\n\n## ta-extension (${by('ta-extension').length})\n\n${table(by('ta-extension'))}\n\n## retired (${by('retired').length})\n\n${table(by('retired'))}\n`;
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  const sites = scanReference(refDir('49577c7'));
  const dir = join(ROOT, 'docs/inventory');
  mkdirSync(dir, { recursive: true });
  const aPath = join(dir, 'b0-assignments.json');
  const assignments = existsSync(aPath) ? JSON.parse(readFileSync(aPath, 'utf8')) : {};
  if (process.argv.includes('--write')) {
    writeFileSync(join(dir, 'b0-candidates.json'), `${JSON.stringify(sites, null, 2)}\n`);
    writeFileSync(join(dir, 'B0-INVENTORY.md'), renderMarkdown(sites, assignments));
  }
  const r = checkAssignments(sites, assignments);
  process.stderr.write(`sites ${sites.length}, unassigned ${r.unassigned.length}, stale ${r.stale.length}, invalid ${r.invalid.length}\n`);
  process.exitCode = r.unassigned.length || r.stale.length || r.invalid.length ? 1 : 0;
}
```

6. Anything in `build-tokenomics-export.mjs` that is QA export → `ta-extension` `exportRow` (A5 will revisit).

### Task 3: Branch-level coverage gate

**Files:**
- Modify: `scripts/coverage.mjs`, `scripts/coverage.test.mjs`
- Create: `corpus/coverage/branch-exclusions.json` (initially `[]`)

**Interfaces:**
- Consumes: Plan 1's `measure()` (it already records `blockRanges` per file and the merged `paint` array).
- Produces:
  - `measure()` additionally returns `deadBlocks: Array<{ id, file, line, col, snippet }>` where `id = "<file>:<line>:<col>:<sha1(snippet).slice(0,8)>"`, `line/col` 1-based from the block's start offset, `snippet` = the source from the block start to the end of that line, trimmed, ≤ 60 chars.
  - `branchGate(deadBlocks, exclusions, totals) → { open: string[], stale: object[], overBudget: Array<{file, excluded, total}>, weak: object[] }` — `exclusions` entries `{ id, kind: 'approved-reachable'|'unreachable'|'failure-only', reason }`; `weak` = entries whose `reason` is shorter than 40 chars or (for `unreachable`) does not cite a line (`/:\d+/`); `overBudget` = files where excluded blocks > 15% of `totals[file]`.
  - CLI: `node scripts/coverage.mjs` gates functions (as today) **and** branches; exit 1 if any open function, stale function exclusion, open branch, stale/weak branch exclusion, or over-budget file. `report.md` gains a "Branch blocks" section listing open ids per file.

```js
import { branchGate, blockId } from './coverage.mjs';

test('blockId is stable and line-based', () => {
  const src = 'a\nif (x) {\n  y();\n}\n';
  const off = src.indexOf('{');
  const b = blockId('f.mjs', src, off);
  assert.match(b.id, /^f\.mjs:2:8:[0-9a-f]{8}$/);
  assert.equal(b.line, 2);
  assert.equal(b.col, 8);
});

test('branchGate: open, stale, weak, over budget', () => {
  const dead = [{ id: 'f.mjs:2:8:aaaaaaaa', file: 'f.mjs' }, { id: 'f.mjs:9:1:bbbbbbbb', file: 'f.mjs' }];
  const ex = [
    { id: 'f.mjs:9:1:bbbbbbbb', kind: 'unreachable', reason: 'short' },
    { id: 'f.mjs:99:1:cccccccc', kind: 'approved-reachable', reason: 'x'.repeat(50) },
  ];
  const r = branchGate(dead, ex, { 'f.mjs': 5 });
  assert.deepEqual(r.open, ['f.mjs:2:8:aaaaaaaa']);
  assert.equal(r.stale.length, 1);
  assert.equal(r.weak.length, 1);
```

```js
export function blockId(file, src, start) {
  const before = src.slice(0, start);
  const line = before.split('\n').length;
  const col = start - before.lastIndexOf('\n');
  const snippet = src.slice(start, (src.indexOf('\n', start) + 1 || src.length + 1) - 1).trim().slice(0, 60);
  return { id: `${file}:${line}:${col}:${createHash('sha1').update(snippet).digest('hex').slice(0, 8)}`, file, line, col, snippet };
}

export function branchGate(deadBlocks, exclusions, totals) {
  const ids = new Set(deadBlocks.map((b) => b.id));
  const exIds = new Set(exclusions.map((e) => e.id));

  return { open, stale, weak, overBudget };
```

```js
#!/usr/bin/env node
// Differential gate (spec §18.2): replay every corpus case against an
// implementation and compare with the reference goldens, both directions, byte for byte.
import { readdirSync, readFileSync, existsSync, statSync } from 'node:fs';
import { join, relative, sep } from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';
import { runCase } from '../replay/runner.mjs';

const ROOT = fileURLToPath(new URL('..', import.meta.url));
export const ENGINE = join(ROOT, 'tokenomics');
const CASES = join(ROOT, 'corpus/cases');

function goldenFiles(dir) {
  const out = {};
  if (!existsSync(dir)) return out;
  const walk = (p) => { for (const e of readdirSync(p)) { const q = join(p, e); if (statSync(q).isDirectory()) walk(q); else out[relative(dir, q).split(sep).join('/')] = readFileSync(q, 'utf8'); } };
  walk(dir);
  return out;
}

export async function diffImpl(implDir, { cases = null } = {}) {
  // Engine-only cases (replay.json "implOnly": "engine") have no reference golden and are not diffed.
  const isDiffable = (c) => existsSync(join(CASES, c, 'replay.json')) && existsSync(join(CASES, c, 'expected/49577c7'))
    && JSON.parse(readFileSync(join(CASES, c, 'replay.json'), 'utf8')).implOnly !== 'engine';
  const list = cases ?? readdirSync(CASES).filter(isDiffable).sort();
  const results = [];
  for (const c of list) {
    const dir = join(CASES, c);
    const assertPath = join(dir, 'assert.json');
    const expectedExits = existsSync(assertPath) ? JSON.parse(readFileSync(assertPath, 'utf8')).exits : undefined;
    const r = await runCase(dir, implDir);
    const gold = goldenFiles(join(dir, 'expected/49577c7'));
    const problems = [];
    r.exits.forEach((code, i) => { const want = expectedExits ? expectedExits[i] : 0; if (code !== want) problems.push(`exit ${i}=${code}`); });
    for (const k of Object.keys(gold)) if (!(k in r.files)) problems.push(`missing ${k}`);
    for (const k of Object.keys(r.files)) if (!(k in gold)) problems.push(`extra ${k}`);
    for (const k of Object.keys(gold)) if (k in r.files && r.files[k] !== gold[k]) problems.push(`differs ${k}`);
    results.push({ case: c, problems });
  }
  return results;
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  const r = await diffImpl(process.argv[2] ?? ENGINE);
  const bad = r.filter((x) => x.problems.length);
  for (const b of bad) process.stderr.write(`${b.case}: ${b.problems.join(', ')}\n`);
  process.stderr.write(`cases ${r.length}, differing ${bad.length}\n`);
  process.exitCode = bad.length ? 1 : 0;
}
```

```js
import { join, isAbsolute } from 'node:path';
import { pathToFileURL } from 'node:url';

export const EXTENSION_API = 1;

export async function loadExtension(settings, engineRoot) {
  if (!settings.extension) return null;
  const p = isAbsolute(settings.extension) ? settings.extension : join(engineRoot, settings.extension);
  const mod = await import(pathToFileURL(p).href);
  if (mod.extensionApi !== EXTENSION_API) throw new Error('tokenomics: extension API mismatch');
  return mod;
}

export function hook(ext, name, ...args) {
  return ext && typeof ext[name] === 'function' ? ext[name](...args) : undefined;
}
```
